MCP 协议：让 AI 连接万物

🗂️ MCP Server

⇄

文件系统 · 数据库 · API · 搜索引擎

💬 MCP Client

⇄

VS Code · 终端 · 调试器 · Git

MCP（Model Context Protocol）是 AI Agent 与外部世界交互的标准协议。 MIMO Agent 作为 MCP Client 能连接各类 MCP Server，调用文件系统、数据库、搜索引擎等外部工具，扩展 AI 的能力边界。

⚡ 工作流程

从想法到代码，只需三步

1

描述你的需求

用自然语言告诉 MIMO Agent 你想做什么。支持中英文混合指令，如"给登录页面添加邮箱验证"、"重构这个函数"、"写一个爬虫脚本"——就像跟同事说话一样自然。

2

AI 分析并规划

ReAct-style Agent Loop 启动：意图路由识别任务类型 → 读取相关文件、理解项目结构 → 制定多步执行计划。你可以实时看到 AI 的每一步思考和决策过程。

3

自动执行并验证

Agent 通过 Workflow/Subagent 协作完成任务：创建文件、修改代码、运行测试、执行命令。完成门控自动验证结果，每一步都可审计、可回滚。完成后汇报详细变更摘要。

快速安装

在 VS Code 中四步完成配置，立即体验 AI 编程

1

在 VS Code 扩展商店搜索 MIMO Agent 并安装

Ctrl+Shift+X → 搜索 "MIMO Agent"
2

打开设置页，选择 MiMo Balance 或 Token Plan 预设

MiMo: Settings → 选择预设方案
3

填写 API Key，保存后选择模型即可开始编程

Save → 选择模型 → 开始对话
