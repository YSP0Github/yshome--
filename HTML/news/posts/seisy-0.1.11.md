# SeisY 0.1.11 发布：月震异常修复更精准，国内下载方式上线

> 发布日期：2026-10-19　|　版本：**SeisY v0.1.11**　|　平台：Windows 64 位

大家好，SeisY **0.1.11** 正式发布。

这一版我们把主要精力放在了「月震数据异常修复」这条核心流水线上——让修复更**精准、可控、看得见**；同时修复了一批下载、启动和界面上的小问题。为了方便国内用户，这一版起**新增了腾讯云内地直链下载**，并建立了官方「云凇之家」QQ 群，以后新版本都能更方便地拿到。

## 一、月震异常修复：更安全、更准确

这是 0.1.11 改动最大的部分。

- **缺失值插值严格限定在你圈选的区间内**：只改选区，选区外原本的 `-1` 丢包标记原样保留，不会再被悄悄改成“真实缺口”。
- **修复“已修改采样点”恒为 0 的统计 bug**：预览里之前处理后一直显示“已修改 0 个点”，实际是 NaN 判定公式的问题；现在如实计数，并且选区中发生改动的位置会用橙色高亮标出。
- **新增“缺样刻度带”**：预览图上一眼看清修复覆盖情况——🔴 红色 = 处理后仍然缺失，🟢 绿色 = 已成功补好。
- **修复“地球数据里的 -1 被误判为缺失”**：`-1` 是阿波罗（XA 台网）月震数据的丢包填充值，而地球、火星数据里的 `-1` 是真实的负样点。现在会按台网区分，地球/火星数据的正常 `-1` 不再误报（此前 G.CAN 等台站下载时误报缺失的问题即由此引起）。
- **“整数化”只对 Apollo 月震数据生效**：导入地球、火星数据时该选项会自动取消并禁用，避免误操作。
- **缺口提示更具体**：下载 / 导入数据时，弹窗会列出每个缺口的**绝对时间位置**，方便定位。
- **工具更快、更稳**：异常修复窗口打开时间由 2–4 秒缩短到约 0.3 秒，不再先闪一个空白窗口；“手动重处理”改为后台加载、不再造成界面假死；“批量去异常”打开时不再疯狂闪烁。

## 二、修复库对比查看器

- 修复了“批量去异常后，已修复的日期全部打不开、左下角报 `name 'rc' is not defined`”的问题。
- 修复了面板中中英文混杂、深浅主题不一致等显示问题。

## 三、数据下载

- **修复弱网 / 校园网 FDSN 下载报错**：此前部分网络下会提示 `no dataselect service`，现对 IRIS 改为跳过 WADL、直连标准端点，下载更稳定。
- **下载参数对话框优化**：台站 / 台网输入框高度统一；通道 / 位置码可编辑下拉框的圆角不再被裁切；开始/结束时间控件、文件树盘符下拉统一换成了更精致的 chevron 箭头。

## 四、启动、更新与界面

- **去掉启动时一闪而过的黑色控制台窗口**，启动页更早出现。
- 修复“检查更新”窗口的标题栏、模态阻塞，以及下载完成后重新打开闪退的问题。
- 数据全览：缩放 / 平移按钮增加了选中态高亮，工具栏不再是灰底。
- 停靠面板（运行信息 / 事件列表 / 天体地图）标题栏重设计，统一为扁平图标按钮，深浅主题下都协调。
- 若干中英文国际化与深浅主题细节修复。

> **⚠️ 关于「内地下载」的安全提示（请务必看一下）**
>
> 腾讯云服务器目前**暂未配置 SSL 证书，只有 HTTP、没有 HTTPS**。因此在 Chrome / Edge 等浏览器里点击「内地下载」时，可能会提示“**无法安全下载**”“**不安全**”，或在下载栏拦截文件。这是 **HTTP 明文下载的常规警告，并不代表安装包有问题**，安装包与 GitHub Release 完全一致。
>
> 正确操作：
>
> 1. 浏览器拦截时，点击右上角/下载栏中的「**保留**」（Keep）；
> 2. 在弹出的二次确认中选择「**仍然保留 / 继续保留**」（Keep dangerous file）；
> 3. 运行安装包时如果出现 Windows SmartScreen 蓝色窗口，点击「**更多信息**」→「**仍要运行**」。
>
> 安装包为 64 位 Windows 正式安装程序（约 774 MB，Inno Setup 打包）。如果你介意 HTTP 提示，也可以直接从 **QQ 群文件**或 GitHub Release 下载。
