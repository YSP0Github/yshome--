📦 MIMO Agent 安装教程

四步完成安装，即刻体验 AI 编程助手

1

打开 VS Code 扩展面板

在 VS Code 中，点击左侧活动栏的扩展图标，或使用快捷键：

Ctrl + Shift + X
💡 也可以在顶部菜单栏选择 查看 → 扩展 打开扩展面板
2

搜索 "MIMO Agent"

在扩展面板顶部的搜索框中，输入 MiMo 进行搜索。

// 在搜索框中输入 MiMo

找到由 mimo-agent 发布的 MiMo 扩展，确认图标为橙色 M 标志。

💡 也可以直接使用命令行安装（打开终端粘贴执行）：
// 在 VS Code 终端中执行 ext install mimo-agent.MiMo
3

安装并启用

点击 MIMO Agent 扩展卡片上的 安装 按钮，等待安装完成。

💡 安装完成后，重新加载 VS Code 窗口（Ctrl + Shift + P → 输入 Reload Window）
4

配置模型与 API

安装完成后，需要配置 AI 模型才能开始使用。打开 MIMO Agent 设置页面：

💡 打开命令面板（Ctrl + Shift + P → 输入 MiMo: Settings）

在设置页面中：

  1. 选择预设模型 — 从预设列表中选择一个模型方案（如 MiMo Balance、DeepSeek、OpenRouter 等）
  2. 填写 API Key — 根据所选模型，填入对应的 API 密钥
  3. 选择模型 — 在模型下拉列表中选择要使用的具体模型
  4. 保存设置 — 点击保存后即可开始对话
💡 如果你使用本地模型（如 Ollama），无需填写 API Key，只需选择 Ollama 预设并确保本地服务已启动即可。
✓

安装完成！🎉

现在你可以直接向 MIMO Agent 发送自然语言命令来编写代码、修复 Bug、重构项目等

试试输入："把按钮改成暗色模式"
